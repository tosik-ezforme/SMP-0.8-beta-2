# LegendaryWeapons — команды, права и разделы меню

Версия под Spigot/Paper 1.21.11. Все админ-команды начинаются с `/legendary` (алиасы `/leg`, `/lw`).

## 1. Права

Сама команда `/legendary` доступна только с правом **`legendary.admin`** (по умолчанию его имеют операторы).
`legendary.admin` включает все остальные права ниже. Отдельное право `legendary.command.*` без `legendary.admin`
команду `/legendary` не откроет — выдавайте помощникам `legendary.admin`.

| Право | Что даёт |
|---|---|
| `legendary.admin` | Всё ниже (по умолчанию: op) |
| `legendary.command.give` | `/legendary give` |
| `legendary.command.reload` | `/legendary reload` |
| `legendary.command.info` | `/legendary info` |
| `legendary.command.progress` | `/legendary progress` |
| `legendary.command.hearts` | `/legendary hearts`, `/legendary revive` |
| `legendary.command.altar` | `/legendary altar ...` |
| `legendary.command.dungeon` | `/legendary dungeon ...` |
| `legendary.command.barrier` | `/legendary barrier ...`, Топор привата |
| `legendary.command.banlog` | `/legendary banlog` |
| `legendary.command.unban` | `/legendary unban` |
| `legendary.command.unique` | `/legendary unique ...`, выдача уникального оружия сверх лимита |
| `legendary.command.cooldown` | `/legendary cooldown ...` |
| `legendary.command.menu` | `/legendary menu` и предмет «Звезда управления» |
| `legendary.altar.break` | Разрушение блоков зарегистрированного алтаря |
| `legendary.banhammer.immune` | Иммунитет к бану от Молота бана |

Команда для всех игроков (без прав): **`/stats`** (алиас `/табло`) — включить/выключить табло статистики справа.

## 2. Команды

### Общие
| Команда | Право | Описание |
|---|---|---|
| `/stats` | нет | Включить/выключить табло статистики (убийства, смерти, время выживания, сердца) |
| `/legendary help` | admin | Список команд |
| `/legendary doctor` | admin | Проверка готовности сервера (память, рецепты, ресурспак, алтари/данжи, права, граница мира) |
| `/legendary reload` | `command.reload` | Перечитать `config.yml` и рецепты |
| `/legendary menu` | `command.menu` | Открыть админ-меню (то же, что ПКМ по Звезде управления) |
| `/legendary info <игрок>` | `command.info` | Сердца, прогресс, перезарядки игрока |

### Выдача предметов
`/legendary give <игрок> <id> [кол-во]` — право `command.give`. Игрок должен быть онлайн.
Доступные `id`:
- оружие: `life_stealer`, `light_blade`, `ender_blade`, `ban_hammer`, `thunderer`, `tecton`, `inferno`, `frost_axe`, `crusher`, `blood_oath`, `phantom`, `prisoner`
- броня: `copper_set` (весь комплект), `copper_helmet`, `copper_chestplate`, `copper_leggings`, `copper_boots`
- прочее: `food_bucket` (ведро еды), `admin_menu` (Звезда управления)
- компоненты крафта: `mace_head`, `axe_head`, `dagger_base`, `armor_plate`

Уникальное оружие, уже существующее на карте, выдаётся только при праве `command.unique` (или `admin`).

### Прогресс, сердца, перезарядки
| Команда | Право | Описание |
|---|---|---|
| `/legendary progress <игрок> <оружие> get` | `command.progress` | Показать прогресс убийств |
| `/legendary progress <игрок> <оружие> set <число>` | `command.progress` | Установить прогресс (нужное число открывает вторую способность) |
| `/legendary hearts <игрок> <set\|add\|remove> <число>` | `command.hearts` | Изменить число сердец |
| `/legendary revive <ник>` | `command.hearts` | Вернуть в игру выбывшего (потерял последнее сердце от Похитителя жизней) |
| `/legendary cooldown list` | `command.cooldown` | Все перезарядки |
| `/legendary cooldown <id> <primary\|secondary\|both> <секунды>` | `command.cooldown` | Сменить перезарядку (`copper_set` — только primary) |
| `/legendary cooldown reset <игрок>` | `command.cooldown` | Сбросить активные перезарядки игрока |

### Лимиты копий на карте
| Команда | Право | Описание |
|---|---|---|
| `/legendary unique list` | `command.unique` | Для каждого оружия: сколько на карте и лимит |
| `/legendary unique limit <оружие> <число>` | `command.unique` | Задать лимит копий на карте |
| `/legendary unique reset <оружие>` | `command.unique` | Удалить все копии оружия с карты (его можно создать снова) |

### Алтари
Право `command.altar`. Типы алтарей = id оружия и частей медной брони.
| Команда | Описание |
|---|---|
| `/legendary altar create <тип>` | Зарегистрировать алтарь на блоке, на который смотрите |
| `/legendary altar build <тип>` | Построить большой алтарь под вами |
| `/legendary altar spawn <тип> [x z] [мир]` | Построить алтарь в точке (без координат — под вами) |
| `/legendary altar random [тип\|all] [мир]` | Случайно расставить алтари по карте |
| `/legendary altar tp <id>` | Телепорт к алтарю |
| `/legendary altar list` | Список алтарей |
| `/legendary altar validate` | Проверить целостность |
| `/legendary altar cancel` | Отменить ритуал на алтаре (материалы возвращаются) |
| `/legendary altar remove` | Убрать алтарь, на который смотрите |

### Данжи
Право `command.dungeon`. Один данж = один ивентовый предмет, лежит на самом дне.
| Команда | Описание |
|---|---|
| `/legendary dungeon spawn [тип] [x z] [мир]` | Построить данж. Типы: `mace_head`, `axe_head`, `dagger_base`, `armor_plate` (без типа — выбирается тот, которого меньше) |
| `/legendary dungeon random [кол-во]` | Случайно расставить данжи по карте |
| `/legendary dungeon list` | Список данжей |
| `/legendary dungeon tp <id>` | Телепорт к данжу |
| `/legendary dungeon refill <id>` | Обновить сундуки и вернуть босса |
| `/legendary dungeon remove <id>` | Убрать из списка (постройку в мире снести вручную, например WorldEdit) |

### Барьеры
Право `command.barrier`. Работает только игроку.
| Команда | Описание |
|---|---|
| `/legendary barrier wand` | Выдать Топор привата (ЛКМ — точка A, ПКМ — точка B) |
| `/legendary barrier pos1` / `pos2` | Точка A / B на вашем месте |
| `/legendary barrier set <x1> <z1> <x2> <z2> [высота_от высота_до]` | Задать область по координатам (без высоты — вся высота мира) |
| `/legendary barrier wall` | Стена из барьеров по периметру области |
| `/legendary barrier fill` | Заполнить всю область барьерами |
| `/legendary barrier clear` | Убрать барьеры в области |
| `/legendary barrier list` | Последние постройки |
| `/legendary barrier remove <id>` | Убрать барьеры записи и саму запись |

Барьеры ставятся только в воздух. Лимиты — блок `barrier:` в `config.yml`.

### Журнал Молота бана
| Команда | Право | Описание |
|---|---|---|
| `/legendary banlog [игрок]` | `command.banlog` | Последние 15 банов Молотом |
| `/legendary unban <ник>` | `command.unban` | Разбан жертвы Молота |

## 3. Админ-меню («Звезда управления»)
Открывается ПКМ по Звезде управления или `/legendary menu` (право `command.menu`).
Главная страница: каждая кнопка подписана табличкой под ней, клик по табличке открывает тот же раздел.
В каждом разделе справа вверху книга «Как пользоваться»: клик по ней присылает описание в чат.

| Раздел | Что делает |
|---|---|
| **Легендарное оружие** | ЛКМ — выдать оружие цели |
| **Предметы** | Медная броня (комплект/по частям), ведро еды, компоненты крафта, звезда |
| **Прогресс оружия** | ПКМ +1, ЛКМ −1, Shift+ПКМ открыть вторую способность, Shift+ЛКМ сбросить в 0 |
| **Заряд брони** | Заряд медного комплекта: ПКМ +1, ЛКМ −1, Shift+ПКМ максимум, Shift+ЛКМ 0 |
| **Сердца** | −1 / +1 / сброс до стандарта, вернуть выбывшего |
| **Алтари** | ЛКМ — построить под вами, ПКМ — случайное место, «расставить все», список с телепортом (броня отдельным блоком справа) |
| **Данжи** | Построить под вами / нужного типа, случайно, обновить все; список: ЛКМ телепорт, ПКМ обновить, Shift+ПКМ убрать из списка |
| **Поставить барьер** | А) по координатам (ввод в чат), Б) Топор привата; стена по периметру, сплошной объём, убрать барьеры; список последних построек |
| **Лимит копий** | ЛКМ лимит +1, ПКМ −1, Shift+ПКМ дважды за 6 с — удалить все копии с карты |
| **Инструменты** | Перезагрузка конфига, сброс перезарядок цели, журнал (последние действия админов и баны Молота) |
| **Цель** (голова) | Выбор игрока, которому выдаются предметы и чей прогресс/сердца меняются |
| **Звезда** | Выдать себе ещё одну Звезду управления |

## 4. Управление способностями (для игроков)
- Первая способность: **Shift + ПКМ** с оружием в руке
- Вторая способность: **F** (смена рук); открывается после нужного числа убийств
- Способности игнорируют броню и Защиту (настройка `abilities.ignore_armor`)
- Табло статистики: `/stats`

## 5. Основные настройки `config.yml`
`abilities.*` (перезарядки, урон), `items.<id>.*` (параметры каждого оружия), `altars.*`, `dungeon.*`, `barrier.*`,
`stats_board.*`, `hearts.*`, `recipes.*`, `resource_pack.*`, `messages.*`. После правки: `/legendary reload`.

## Дополнения (запуск на 50 игроков)

- **Админские предметы** (Звезда управления, Топор привата): у игрока без `legendary.admin`/op не работают, не подбираются,
  не перекладываются и раз в `admin_guard.interval_ticks` изымаются из инвентаря (запись в журнал).
- **Чертёж** (`/legendary give <ник> blueprint_<компонент>`, например `blueprint_axe_head`): книга с рецептами оружия,
  использующего компонент. Лежит в нижних сундуках данжа: за боссом 100%, в боковых 20% (`dungeon.loot.tierN.recipe_chance`).
- Ивентовый предмет в боковых сундуках: **20%** (`dungeon.loot.tier2.chance`), за боссом 100%.
- Мобы (зомби и др.) не активируют нажимные плиты в данжах — ловушки срабатывают только от игроков.
- Подземные алтари при `/legendary altar random`: `altars.random.underground.*` (глубинная тьма, иначе глубоко под землёй;
  тип `tecton` по умолчанию всегда под землёй).
- Единственная команда без прав: `/stats`. Все подкоманды `/legendary` проверяют права; сама команда закрыта в plugin.yml.

## Обновление: мешочки, книги, плетение

- **Мешочек** (`/legendary give <ник> pouch`, крафт: нить сверху + кожа рамкой `S / L_L / LLL`): ПКМ — открыть, 3 стака внутри.
  Не более `pouch.max_per_player` (3) у игрока; при попытке взять 4-й: «Взять ещё не получится…». Оружие, броню, шалкеры и мешочки класть нельзя.
- **Книга рецептов** (`give <ник> recipe_book`) и чертежи (`blueprint_<компонент>`) — в админ-меню: Предметы → «Книги рецептов».
  В данжах книги больше **не появляются** (`dungeon.loot.tierN.recipe_chance: 0`).
- Меню «Предметы» теперь по категориям: Медная броня / Компоненты / Книги рецептов / Прочее.
- Поножи дают «Плетение» (уровень 2, `copper_armor.leggings.weaving_level`).
- В общий чат: «погиб и выронил легендарный предмет» и «уничтожен в пустоте» (с ником, в т.ч. «выпала при смерти»).
